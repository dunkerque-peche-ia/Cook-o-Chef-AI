# 🍲 Cookéo Chef AI & Couvercle Extra Crisp

Assistant culinaire intelligent sur-mesure pour tous les modèles de **Moulinex Cookéo** (Cookéo Touch, Touch Pro avec balance, Cookéo + / Classique, Cookéo Mini 3L, Cookéo Gourmet/Infinity) avec prise en charge complète du couvercle **Extra Crisp (Air Fryer)** et de tous les accessoires compatibles.

---

## ✨ Fonctionnalités Clés

1. **Sélection du Modèle de Cookéo** :
   - **Cookéo Touch / Touch WiFi** : Cuve 6L, écran tactile, 1600W.
   - **Cookéo Touch Pro** : Avec balance intégrée au gramme près.
   - **Cookéo + / Classique / Bluetooth** : Le modèle culte avec molette centrale "Turn & Click".
   - **Cookéo Mini (3 Litres)** : Format compact (1 à 4 convives, règles de liquide adaptées à 150 ml).
   - **Cookéo Gourmet / Infinity** : Finition inox et cuve haute résistance.

2. **Écosystème d'Accessoires Pris en Compte** :
   - **Couvercle Extra Crisp** (1300W - 4 programmes : Rôtir, Griller, Frire sans huile, Cuire gâteau).
   - **Panier vapeur inox** (légumes croquants, poissons et papillotes).
   - **Moule à gâteau Cookéo antiadhésif** (avec anse relevable).
   - **Set de 6 Verrines / Pots en verre vapeur** (flans, crèmes dessert, compotes).
   - **Couvercle de conservation silicone** (mise au frais directe).
   - **Pince thermo-isolante** (retrait sécurisé du moule ou panier brûlant).
   - **Séparateur de cuve 2 zones** (cuisson double simultanée).

3. **Les Modes de Cuisson Calibrés** :
   - **Mode Dorer (160°C)** avec rappel systématique de **déglaçage des sucs** pour éviter l'erreur "Aliment brûlé".
   - **Cuisson sous pression (Rapide)** avec respect strict de la **règle des 200 ml de liquide minimum** (évite le Code Erreur 21).
   - **Cuisson Vapeur** douce.
   - **Option Extra Crisp** pour une finition croustillante et gratinée au sommet du plat.

4. **Intelligence Artificielle & Personas de Chefs** :
   - 5 chefs aux personnalités uniques : *Coach Débutant Cookéo*, *Mémé Gâteau*, *Chef Étoilé*, *Chef Express & Rigolo*, *Chef Rock & Extra Crisp*.
   - Intégration de l'API Google Gemini (avec fallback intelligent sur le catalogue hors-ligne en cas de coupure réseau).

5. **Mode Live Cooking (Cuisiner en Pas-à-Pas)** :
   - Minuteur interactif avec bips audio officiels Cookéo (Web Audio API).
   - Synthèse vocale française pour écouter les consignes les mains libres.
   - Liste à cocher des ingrédients.

---

## 🚀 Lancer l'Application

Depuis le terminal :
```bash
cd cookeo-chef-ai
node serve.js
```
Puis ouvrez votre navigateur sur [http://localhost:3001/](http://localhost:3001/).
